## 1.1 ROS 2 是什么

ROS（Robot Operating System）不是操作系统，而是一套**分布式通信框架 + 工具集 + 软件生态**。ROS 2 相比 ROS 1 的核心变化：

| 特性 | ROS 1 | ROS 2 |
|------|-------|-------|
| 通信中间件 | 自研 TCPROS/UDPROS | DDS（默认 Fast DDS） |
| 主节点 | 需要 roscore（单点故障） | 无主节点，节点自动发现 |
| 实时性 | 差 | 支持实时系统 |
| 系统支持 | 仅 Ubuntu | Linux / Windows / macOS |
| 进程内通信 | 无 | 支持（零拷贝） |

**核心概念速览**（后续章节会逐个深入）：

- **节点（Node）**：最小的执行单元，一个节点负责一项具体功能
- **话题（Topic）**：多对多异步通信，发布/订阅模型
- **服务（Service）**：一对一同步通信，请求/应答模型
- **动作（Action）**：带反馈和取消的长时间任务
- **参数（Parameter）**：节点的运行时配置项
- **包（Package）**：代码组织单元，含 `package.xml` 清单
- **工作空间（Workspace）**：`src/ build/ install/ log/` 四个目录

## 1.2 本教程环境

- WSL2（Linux 6.6，Ubuntu 22.04 jammy）
- ROS 2 **Humble Hawksbill**（LTS，支持到 2027 年 5 月）
- 编译器：g++（C++17），构建工具：colcon
- 安装类型：`ros-humble-desktop`（含 RViz2、turtlesim、TF 等）

### 安装参考（已装好，无需重复执行）

```bash
# 添加 ROS 2 源
sudo apt update && sudo apt install curl gnupg lsb-release
sudo curl -sSL https://raw.githubusercontent.com/ros/rosdistro/master/ros.key -o /usr/share/keyrings/ros-archive-keyring.gpg
echo "deb [arch=$(dpkg --print-architecture) signed-by=/usr/share/keyrings/ros-archive-keyring.gpg] http://packages.ros.org/ros2/ubuntu $(. /etc/os-release && echo $UBUNTU_CODENAME) main" | sudo tee /etc/apt/sources.list.d/ros2.list > /dev/null

sudo apt update
sudo apt install ros-humble-desktop python3-colcon-common-extensions
```

## 1.3 环境变量：为什么每次都要 source

ROS 2 命令（`ros2`、`colcon build` 时找到依赖）依赖一组环境变量，它们由安装目录下的 setup 脚本设置：

```bash
source /opt/ros/humble/setup.bash    # 启用 ROS 2 环境（每个新终端都要执行）
printenv ROS_DISTRO                  # 输出 humble 即成功
```

**本教程 workspace 约定**：所有 colcon 命令在 `cpp/` 目录下执行：

```bash
source /opt/ros/humble/setup.bash
cd ~/myProgramFile/learnRos2/cpp
colcon build                        # 编译 src/ 下所有包
source install/setup.bash           # 让 ros2 run 能找到你自己编译的包
```

> 💡 想免去每次 source：把 `source /opt/ros/humble/setup.bash` 加入 `~/.bashrc`。
> ⚠️ 注意不要同时 source 不同 ROS 发行版，也不要反复 source install/setup.bash（叠加会污染环境，新终端重新 source 即可）。

## 1.4 海龟模拟器：第一个"机器人"

turtlesim 是 ROS 2 自带的 2D 模拟器，本教程 ch3/ch4 都会用到它：

```bash
# 终端1：启动模拟器（需要图形界面，WSL2 依赖 WSLg）
ros2 run turtlesim turtlesim_node

# 终端2：用键盘控制海龟移动
ros2 run turtlesim turtle_teleop_key

# 终端3：查看当前话题/节点图
ros2 node list
ros2 topic list
ros2 node info /turtlesim
```

> 在 WSL2 下如果窗口不显示，确认 WSLg 可用：`echo $DISPLAY` 应输出类似 `:0`。纯终端环境可先跳过图形界面，直接学习 ch2 起的概念。

## 1.5 Linux 基础速查（ROS 开发高频命令）

```bash
sudo apt update && sudo apt install <包名>   # 安装软件（ROS 包命名：ros-humble-xxx）
dpkg -l | grep ros-humble-                  # 查看已安装的 ROS 包
find /opt/ros/humble -name "*.hpp"          # 找不到头文件时去 ROS 安装目录搜
ldd <可执行文件>                             # 查看动态库依赖
```

## 1.6 练习

1. 运行 turtlesim，用 `ros2 node info /turtlesim` 观察它发布了哪些话题、订阅了哪些话题。

3. 尝试 `ros2 run turtlesim turtlesim_node --ros-args --remap __node:=my_turtle`，体会节点重命名。
