# ROS 2 学习教程目录

基于《ROS 2机器人开发：从入门到实践》（鱼香ROS·桑欣著，机械工业出版社 2024），按书本章节顺序组织。

每章包含：
- **一份学习文档**：`docs/chXX_主题.md`（概念讲解、代码逐段解析、编译运行步骤、常见坑、练习题）
- **一个可执行程序/项目**：位于 `cpp/src/` 下对应包

环境：ROS 2 Humble（Ubuntu 22.04 / WSL2），语言以 C++ 为主。

状态图例：✅ 已生成并验证 ｜ ⚠️ 已生成，运行需先安装依赖 ｜ 🔄 进行中
